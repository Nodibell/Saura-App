# Media Directory

This directory stores visual assets, screenshots, and demonstration recordings for Saura Workbench.

## Organization
- `branding/`: App icons, logos, vector banners.
- `screenshots/`: High-resolution UI screenshots (macOS Dark & Light mode).
  - `01_summary_view.png`: Dataset overview, summary statistics, modality inference.
  - `02_forecasting_view.png`: Time series Holt-Winters forecast, S-ESD anomalies.
  - `03_shap_beeswarm.png`: Feature impact beeswarm & PDP curves.
  - `04_data_drift.png`: Wasserstein distance & PSI covariate shift sentry.
  - `05_ai_analyst.png`: ReAct autonomous analyst dialogue.
- `videos/`: Short demonstrations (.mp4 / .webm) and animated GIFs for the repository header.
